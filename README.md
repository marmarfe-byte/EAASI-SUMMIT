# EAASI Partners Summit 2026 — Event App

Installable PWA built per [`design_handoff_eaasi_summit_app/BRIEF.md`](../design_handoff_eaasi_summit_app/BRIEF.md). Plain HTML/CSS/JS (ES modules, no bundler, no framework) — no `npm install` or build step required.

## Run locally

Any static file server pointed at this folder works. From this directory:

```
npx serve .
```

or open `index.html` through any static server (not `file://` — `fetch()` of `content/*.json` needs `http://`).

## Deploy

Static hosting only (Vercel / Netlify), root = this `app/` folder, no build command needed. Serve over HTTPS (required for installability + service worker) at a short custom domain (e.g. `summit.eaasi.eu`) per the brief's distribution plan.

## Editing content

Everything under `content/*.json` drives the UI directly — edit those files (no code changes, no redeploy build step) to update agenda, speakers, sponsors, etc. Values marked `"PLACEHOLDER — ..."` are shown in the app with the `PLACEHOLDER — ` prefix stripped (so the app is browsable/demoable now); replace them with real content before launch. See `design_handoff_eaasi_summit_app/README.md` → "Assets Needed Before Development" for the full checklist (logo, sponsor logos, speaker photos, venue address, etc.).

## Logo & icons

`icons/icon-192.png`, `icons/icon-512.png` and `assets/eaasi-logo.png` are generated by `generate-icons.ps1` from the real logo (`../EAASI_Summit_26_Logo_Square.png`) — auto-cropped, background removed for the hero asset, composited on white for the app icons (maskable-safe). Re-run the script if a new/updated logo file is supplied.

Sourced so far from the brief, `BM52_EAASI_def.pptx`, `hotelalicantegolf.com`, `eaasi.eu/summit2026`, and the restaurants' own sites — see fields still marked `TBC` / `PLACEHOLDER` in `content/*.json` for what's outstanding, notably: speaker photos, exact room names/capacities at Hotel Alicante Golf, dress code, Wi-Fi/app-support FAQ answers, event organizer emergency hotline, and the Friday networking tour details.

## Structure

- `index.html` — single entry point, loads `css/styles.css` + `js/main.js`
- `js/main.js` — hash-based tab router, app state, event delegation
- `js/components/*.js` — one render function per IA section
- `js/data.js`, `js/utils.js`, `js/icons.js` — content loading, formatting helpers, inline SVG icons
- `manifest.json`, `service-worker.js` — PWA install + offline caching (app shell cache-first, `content/*.json` network-first with cache fallback)
